# ePiata

ePiata este o platformă de marketplace dezvoltată în PHP și MySQL, care permite utilizatorilor să descopere produse, să le adauge în coș, să salveze produse favorite și să plaseze comenzi.

## Funcționalități

- Înregistrare și autentificare utilizatori
- Gestionarea utilizatorilor
- Categorii de produse
- Coș de cumpărături
- Produse favorite
- Comenzi
- Plăți
- Recenzii
- Dashboard
- Statistici
- Trimitere email
- Bază de date MySQL

## Tehnologii

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Composer
- PHPMailer

## Structura proiectului

### `includes/`

Conține serviciile aplicației și conexiunea la baza de date.

### `pages/`

Conține paginile aplicației.

### `public/`

Conține punctul principal de intrare al aplicației și fișierele publice.

### `database.sql`

Conține structura și datele inițiale ale bazei de date.

## Instalare

1. Clonează repository-ul:

```bash
git clone LINK_REPOSITORY
```

2. Intră în proiect:

```bash
cd ePiata
```

3. Instalează dependențele:

```bash
composer install
```

4. Creează baza de date MySQL.

5. Importă fișierul:

```text
database.sql
```

6. Configurează conexiunea la baza de date.

7. Pornește proiectul.
